## 5. Scenario-Based Demo & Practice Questions

### Question 1
An enterprise requires archival storage for compliance files that must be retained for 7 years but will rarely be accessed. Cost minimization is the primary goal. Which OCI storage tier should be chosen?

A) OCI Archive Storage Tier
B) Block Volume Ultra High Performance
C) File Storage Service Standard
D) Local NVMe SSD

- **Correct Answer**: `A) OCI Archive Storage Tier`  
- **Technical Explanation**: OCI Archive Storage provides the lowest cost storage tier for long-term retention. It requires an unarchive request (taking a few hours) before data can be read.

---

### Question 2
What feature allows an administrator to dynamically adjust the IOPS and throughput performance of an attached OCI Block Volume without detaching it or restarting the compute instance?

A) Dynamic Performance Level Tuning
B) Reformatting the file system
C) Changing the VCN subnet CIDR
D) Migrating to an Archive bucket

- **Correct Answer**: `A) Dynamic Performance Level Tuning`  
- **Technical Explanation**: OCI Block Volumes allow you to dynamically modify performance tiers (e.g. from Balanced to Higher Performance) on the fly with immediate effect and zero downtime.
